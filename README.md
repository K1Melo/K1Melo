### ⚡ Ambar – Energy-Efficient Compiler Development  
**C++20 | LLVM | Compilers | Systems Programming**

📅 Dec 2024 – Present  
🏆 Podium finish at **Robótica Paula Souza Hackathon**  
📍 Presented at **FETEPS**

Ambar is a **high-performance, energy-efficient compiler** developed in **C++20** and integrated with **LLVM**.

I implemented the complete compiler pipeline, including:
- Lexical analysis with **Flex**  
- Syntax analysis with **Bison**  
- **AST construction and semantic analysis**  
- Optimized LLVM IR code generation  

The compiler achieved up to **36% energy efficiency improvement** compared to C in the π benchmark.

**Key Contributions**
- Modular LLVM IR generator supporting functions, basic blocks, and variables  
- Cross-platform compatibility across **x86, ARM, and RISC-V**  
- Compile-time optimizations such as:
  - Constant folding  
  - Constant propagation  
  - Expression pre-evaluation

### 🌱 Smart Terrarium API  
**IoT | Java | Spring Boot | PostgreSQL | Docker | ESP32**

Smart Terrarium API is an **Internet of Things (IoT)** solution designed to **monitor and automatically control environmental conditions** inside a terrarium.

The system integrates an **ESP32 microcontroller**, a **cloud-based backend**, and a **web application** to provide **real-time monitoring** and **remote device management**.

Environmental data such as **temperature**, **humidity**, and **light intensity** are collected via sensors connected to the ESP32 and transmitted to the cloud through **RESTful APIs**. The backend, built with **Java and Spring Boot**, processes and persists the data using **PostgreSQL** and exposes endpoints for real-time visualization and device control.

The application allows users to configure automation rules to control devices such as **heating lamps** and **ventilation systems** remotely.

**Key Features**
- Real-time monitoring of environmental conditions  
- Automated control based on predefined rules  
- Remote access via web application  
- Cloud communication using ESP32 and REST APIs  
- Containerized backend using Docker
